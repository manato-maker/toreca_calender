相場について

カードは登録全件を型番・レアリティまで再照合し、ポケカチの素体買取を反映。仕様が確定できないカードは相場未取得のまま表示します。BOX・未開封商品は買取ミミとAMTFを手入力し、別履歴で保存します。相場を更新するたび履歴を保存し、上昇・下落ランキングを自動計算します。相場未入力の商品は推定総資産・含み損益・ランキングから除外します。相場ソース：ポケカチ掲載の買取価格。型番・レアリティ・未開封条件を確認できた値だけ登録します。
GitHub Pages上のアプリ本体を更新しても、同じブラウザの端末内データは引き継ぐ設計です。大きな更新前にはバックアップ推奨。
